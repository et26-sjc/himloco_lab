# Go1 下一次落足的强冲击风险：面向提前干预的研究方案

状态：2026-11-08，根据研究目标重新设计；尚未进行本阶段采集、训练或下游干预。分支 `feat/go1-impact-anticipation`。这是可执行实验协议的设计稿，不冒称已完成预注册或验证。旧实验、模型和结论保留。

同日复盘后的执行顺序见[研究总复盘](GO1_IMPACT_RESEARCH_SUMMARY.md)：N0时间/动作响应开发→N1未来预测正式主实验→N2适配/Replay→N3物理作用验收。N0先检查20ms是否足够；若不足，在正式训练与测试前锁定更长最低提前量，仍完整报告20/40ms。这是未执行设计的修订，不修改历史实验结果。

## 目标与可证伪主张

目标是：**在下一次落足产生冲击之前，用部署可得的本体历史估计其强冲击风险，给下游动作留下实际可用时间。** 当前阶段不再以“识别刚发生的冲击”作为主要成功标准。

第一项明确任务限定为下一次落足，而不声称覆盖全部物理冲击。普通落足一定会产生接触力；需要预测的是其是否出现超过操作性阈值的快速加载，而不是脚是否将接触地面。支撑期再加载、短重接触和脚撞台阶立面应单独标注、分析；若未纳入主标签，不能将其中的真实冲击全部解释为无意义误报。

主张分三级验证，互不替代：

1. 本体历史是否对**未来强落足**包含超过落足时序/相位代理的风险信息？
2. 能否在完整连续流中，以足够提前量和可接受的误动作预算利用这些信息？
3. 在报警次数、提前时刻和动作幅度配平后，风险预测是否比仅按落足相位执行同样动作带来额外物理收益？

前两项通过不自动证明第三项。第三项没有收益也不自动否定前两项；可能是动作不足以改变目标，需对应的干预参照定位。

## 与已有实验的关系

[早期 P20](GO1_FORCE_LOADING_RATE_RESULTS.md)在输入截止时预测下一20 ms区间，其目标包含已接触后的后续加载，滤波历史也可能早于截止时刻。预测区间长度不是保证的提前量。该实验保留为参考，不作为严格接触前预测的证据。

[上一阶段](GO1_IMPACT_CAUSAL_STREAM_RESULTS.md)验证了接触后40 ms内的连续识别，暴露了冻结严重度头、背景监督、阈值迁移和超时计分问题。不能将该阶段的3.3%/43%检出率当作本阶段未来预测的基线，亦不继续将该冻结头直接接到一个学习触发器上。

下一阶段从开始就用未来标签训练。所有决策时刻均进入连续流评价；不由真值起点挑选何时运行模型。原生接触真值只用于构造训练监督、审计和离线分层。

## 明确的预测对象

在观测截止时刻t，H_t为仅包含t及更早时刻的六帧45D本体历史。对足i，c_i(t)是严格晚于t的**第一次符合定义的落地**，S_i是该落地的严重度。第一版沿用已有落地定义：之前连续40 ms接触合力幅值<=5 N，随后两个400 Hz样本>5 N；S_i为落地后40 ms内的因果20 ms平均、20 ms滞后正差分峰值。强事件阈值u=2000 N/s，仅为操作性定义，不是损伤界限。

主输出为

\[
p_i(t)=P\{0<c_i(t)-t\le80\,\mathrm{ms},\;S_i>u\mid H_t,a_t\}.
\]

这定义了有限80 ms窗口内**下一次落足**的强冲击概率：如果下一次是普通落足，即使随后还有强落足，也不能将前者预测成强事件。无落足、普通落足和强落足在数据中明确区分；不能只在未来确定落足的样本上训练、再声称解决了完整任务。

当前a_t是t时刻已经由冻结策略计算、尚未执行的动作。首次主比较使用相同H_t，不强制增加动作输入；显式a_t是单列消融。对于确定性冻结策略，a_t由H_t决定，并非凭空增加传感信息，但在后续策略或动作分支变化时，必须明确动作条件。不得使用未来实际动作序列或未来状态作为部署输入。

主训练目标是未来事件概率，**主验收只认有效提前量达到N0开发阶段锁定的L_min的报警**；首个报告档位为20ms，40ms为关键次级指标。若动作响应要求L_min>20ms，在正式训练/测试前记录并锁定，仍保留20/40ms完整结果。主未来窗口固定80ms，不能与20/40ms最低提前量档位混淆。若另做20/40ms未来窗口消融，须构造各自匹配标签并列为次级，不能把80ms分数当成短窗口概率或在测试后挑主任务。辅助连续回归目标是同一未来80ms内下一次落足的S_i，无未来落足时为0；其目标统计量不同，不能仅据其风险排序弱就判MSE不能学习幅值。

如果记录在t+120 ms前结束或跨episode，可能无法确定80 ms内落足的完整40 ms严重度，不得默认标为负例。根据原生时间和episode完整性做删失，保留原因与被排除事件数。

## 有效提前量与接触前审计

输入截止、最新传感样本时间、推理结果可用时间、指令发送时间及估计执行生效时间分别记录。有效提前量定义为

\[
\ell_i=c_i-(t_{\rm result}+d_{\rm communication}+d_{\rm actuator}).
\]

传感陈旧已经包含在输入截止与结果可用时间之差中，不重复扣除。50 Hz本体输入意味着观测边界间隔20 ms，不能无依据再固定加20 ms通信延迟。报告零人为延迟及额外10/20 ms链路时延的敏感性；这些是可用时刻移动，不伪造50 Hz下不存在的中间传感样本。实测的推理耗时与预设通信/执行延迟分开列出。

其中d_actuator只指指令到可检测运动响应开始的死区；L_min是响应开始后仍需保留的动作发展时间。N0同时记录总预备时间及这两个部分，不把同一段执行响应既从有效提前量扣除又计入L_min。若无法分辨死区，改用接触起点减指令发送时刻作为总提前量，并将包含死区的总需求用作该口径阈值，不再另扣d_actuator；正式协议锁定后不混用两套阈值。

只有在结果可用时刻早于原生落地起点且有效提前量>=L_min的报警，才能计入主提前检出率。强冲击发生后才上升的分数、或者仅在滤波率峰前但原生接触后出现的报警，均单列为反应性识别。20ms是首个报告档位，不代表已证明执行器20ms即可发挥作用；N0测量最低动作响应时间后锁定L_min，N3再验收收益。当前主机batch1部署模型的实测推理时间与Go1机载推理/真实执行器延迟分别标记，未在硬件测量的延迟不能冒称已验收。

采集需增加离线用的足端几何/接触审计信息，核对第一接触对、阈值起点与实际足端间隙之间的差别。若无法可靠获取几何接触真值，只能称为力阈值定义之前的预测，不能声称严格几何接触前预警。这些字段不得进入候选网络、部署门控或下游动作路径。

## 第一阶段：未来风险是否有实际可用信息

保留冻结HIMLoco-Go1 PD行为策略、Kp40/Kd1、动作尺度0.25；400 Hz物理、50 Hz策略与本体输入。4096总环境，五组独立采集、两组网络初始化。沿用六类训练地形和箱块留出、普通速度0.4–0.9与提速1.0–1.1 m/s，4秒episode；起始平台与实际障碍区分开报告。材料/动力学变化另作后续独立shift，不在本阶段同时增加所有因素。

只使用新的开发、训练、验证和最终测试种子。各阶段不能读取后续测试标签；旧数据如因存储清理需重采，准确标记为再采集，不宣称PhysX逐位复现。完整传感缓存逐角色暂存；保留小型完整输入/原生接触审计、标签、报警和有效权重，核验归档后清理大数组，不恢复旧220 GiB。

N1拟采集每数据复制train2500、validation600、test600、high_speed600个策略步，五组共88,064,000个机器人区间，四足不作四倍独立重复。正式开发seed=9500，train=9101–9105、validation=9201–9205、test=9301–9305、high_speed=9401–9405；实现前核对现有采集provenance未使用这些seed，冲突只在正式采集前替换。主模型从头训练，同输入的模型共享配对初始backbone/采样顺序但独立参数及optimizer，不将旧接触后严重度初始化混入主损失对照。

必要的公平对照：

| 方法 | 目的 |
|---|---|
| 常数风险、只预测落足时序/相位代理 | 排除事件频率与正常步态规律造成的表面预测能力 |
| 完整本体历史，未来事件BCE | 最简单、直接的未来风险基线 |
| 相同输入、相同二值目标的概率MSE/Brier | 隔离目标统计量与损失形式；承接已有结果，不重新宣称首次发现 |
| 完整本体历史，未来连续严重度MSE | 保留数值回归参考；另报告物理单位误差及尾部 |
| 时间与强弱联合输出 | 候选小模块，检验显式区分“何时落足/是否强冲击”有无额外用途 |

候选联合输出使用下一次落足的(0,20]、(20,40]、(40,80] ms三时间档，每档分普通/强冲击，另有80 ms内无落足，共7类/足；其概率相加可恢复同一个未来80 ms强冲击目标。它是一次软联合预测，不采用“先硬判接触，再选冻结严重度头”。时间档、更丰富监督与输出参数量均是额外条件，应与同等参数/训练量对照比较，不能把多任务监督收益直接归为新结构收益。该结构目前是候选，已有有序头未获优势的旧结果仍保留。

主比较使用相同未来强事件目标与报警规则。若另用联合时间档过滤过近事件，需要增加具有同一“可动作窗口”标签的直接BCE参考，将决策规则与表示结构收益分开。

主比较固定为完整历史BCE相对相位代理BCE的**有效提前量>=L_min的事件检出率**，阈值只在验证训练家族上选择，测试FAR上界<=1次/机器人分钟，检出率配对差95%CI下界>3个百分点。验证集以<=0.5/min的误动作上界留裕量；统计先平均两初始化，再以五数据复制和tile聚类分析。不因主判据失败改用某个更晚时刻的高AUC宣布成功。

训练量在新的开发集完成收敛检查后、正式实验前锁定，起始预算参考早期未来任务60000更新、batch2048；主目标/模型的更新和样本预算匹配。不能只因4096 env就认定充分训练。正式模型与工作点全部锁定后，再打开最终测试。不能沿用事后已经观察过的新任务测试集调参。

## 连续流报警与防止“预测周期落足”捷径

报警只由模型输出和部署已知状态产生，绝不利用未来真值来安排推理或取消报警。每足统一采用此前100ms同episode分数安静的因果去重规则，候选报警在结果可用时产生。离线一对一匹配下一次同足落地：主命中要求有效提前量>=L_min、输入截止后80ms内的下一次落足为强事件；20/40ms档位另报，晚于L_min者计为过晚，未来80ms内无对应目标者为无效预备。事件分母需有至少一次有效预测机会（burn-in后且完整未来、输入截止后80ms内、动作生效前距起点>=L_min），并完整列出缺机会/删失数；该判断只用于离线计分，不能控制模型运行。重复预测单列。保守工作点将未及时命中的动作均计入无效动作预算，同时另报纯背景、普通落足、超时强事件，避免“误报”一词掩盖物理含义。

同时报告自然连续流指标，以及**条件于下一次确有落足时的普通/强落足区分度**。后者可用于离线分析，不能变成只挑好样本的部署评估。分足、接触前相位、指令、地形与障碍/平台区域统计；真实接触时刻、地形编号仅用于评价。

相位参考即使准确预测所有落足，若不能区分普通与强落足，仍应消耗对应误动作预算。候选网络必须在相似落足相位、运动状态条件下提供额外严重度信息。隐藏承接面配对实验可复用原机制：本体前缀近似相同而未来不同，用于检验概率不确定性；不能用其构造性模糊结果断言自然行走所有未来都不可预测。

若低频提前预测失败，先对照同一时间跨度、更高频且噪声配平的部署可得输入，再检查表示或传感限制。高频输入和无噪声必须分开消融，不允许混合提升。不能把接触发生后获得的高频力学响应计作提前预测收益。

## 第二阶段：面向未来任务的适配与Replay

无需等所有未见场景泛化成功，才讨论适配。第一阶段只要建立超过相位参考的、达到最低应用要求的提前预测能力，就在**同一未来标签**下比较冻结、仅新域微调、Stage-0 anchor、同字节随机Replay及同计算量近期样本重训。模型输入、未来窗口、阈值评价口径保持一致；保留旧/新固定验证集，分别记录排序退化、概率/阈值漂移、提前量变化。

记忆必须覆盖未来强事件前的真实因果前缀、普通落足和容易误动作的背景；标签需要未来观察才能成熟，buffer只能在所需未来窗口完成后入库，不得在尚未观察未来时使用标签更新。目标更新时，不能直接把“已经发生事件”的旧标签混入新任务。公平报告追加旧样本和固定总batch替换样本的区别。

Replay只用于学习中保持已有预测能力，不保证提高对从未到达场景的可预测性，也不提供额外提前量。仿真可以获得成熟的privileged监督；真机缺少等价监督时，不得直接宣称相同算法实现了硬件无标签在线适应。

## 第三阶段：预测究竟能否帮助动作

先选择一种独立于旧learned admittance的、幅度受限的预备动作，并通过相同初始状态的短时仿真分支验证其在不同提前量下有无物理作用。具体动作与幅度须根据响应实验决定，不先指定改Kp/Kd或假定某个动作必然减冲击。若动作本身对目标无效，不通过继续训练预测器掩盖。

动作最小响应时间检查前移到N0开发阶段，N3才验收风险触发的最终物理收益。分支首先通过重复无干预A/A核对完整状态或共同前缀重演误差；只复制root/joint状态不保证恢复PhysX全部求解历史，不据此宣称精确相同状态的因果对照。

之后固定预测器与动作映射，至少比较：无预备、相位触发同动作、风险触发同动作、报警频率/提前时刻/幅度配平的随机参考，以及使用仿真无干预未来标签安排的诊断性预备参照。最后一个读取未来，只能作为非部署参照；各分支必须从相同真实状态独立重演，不能将已改变后的接触标签当作原风险标签。

指标包含固定无干预风险集合上的实际加载、滤波loading-rate、冲量、跟踪与姿态代价、跌倒及非必要动作率。不能在干预后因事件降低而将它从测试分母删掉。原生峰对求解步长的敏感性沿用既有物理审计，不以单步导数下降单独证明实用减冲击。

风险触发相对仅按相位做同样动作，有一致的额外物理收益且不靠更多动作次数/幅度，才能形成面向作用的小模块创新证据。若只有排序收益、没有提前量或物理收益，应保留为条件风险估计模块，准确定位用途。

## 本次设计完成后的交付边界

已改变的是下一阶段的任务定义、对照和成功标准，尚未运行新实验。正式实现前需在独立开发数据上确认：几何接触审计接口、未来标签删失、报警一对一匹配、延迟时间戳，以及可产生物理作用的动作响应时间。原生标签可未来成熟，但网络输入与动作绝不读取未来。
