## 2. 要检验的四个问题

| 问题 | 隔离方法 | 支持与反证 |
|---|---|---|
| Q1：是否存在学习诱发的遗忘？ | 新域学习前后重复评同一旧域集合；对照冻结模型和 A→A→A | 只有同一个旧测试任务在更新后退化才是遗忘；原本 U 域差不算 |
| Q2：有限记忆能否改善保留，代价多大？ | finetune、FIFO、随机 reservoir，同 batch/更新次数 | 旧域改善需同时报告新域适应损失；不能以冻结模型的保留冒充适应 |
| Q3：严重度记忆是否有额外价值？ | 严重度分层 vs 等字节随机、普通二值分层；加权/不加权消融 | 仅胜无 Replay 不足以构成该模块贡献；仅胜随机也可能只是普通类别平衡收益 |
| Q4：退化主要在表示还是决策工作点？ | 同时看 raw AP、Brier、固定校准器/阈值、单独的再校准诊断 | AP 稳定、FAR 漂移提示决策/校准问题；AP 退化且校准不能恢复则提示排序能力损失，仍不是信息论证明 |

先回答这四项，之后再研究网络架构、自动触发更新、PPO 联合训练或控制收益。不能把所有因素同时改动后，将改善归因于 Replay。

## 3. 固定的任务与输入

沿用冻结 HIMLoco-Go1 PD 行为策略、Kp=40、Kd=1、动作尺度 0.25。研究采集仍为 **4096 env、物理 400 Hz、策略 50 Hz**。指令固定 `(0.7, 0, 0)`，首轮只变化地形几何；材质、质量、速度、推扰另立后续实验。

沿用 I0 的 45×6 本体历史、128/64 MLP 和上一阶段的配置观测噪声。初始归一化统计只从 A 训练集拟合，整个序列冻结；避免运行均值漂移成为额外原因。仿真 privileged force 只用于监督、记忆分层和评价，不进入部署输入。

主任务为 **D：识别刚完成 20 ms 区间的 S20>2000 N/s 事件**，主预测头为自然采样 BCE。Brier 作为第二损失复验；F20/L20/S20 连续 MSE 作为数值参考。P20 为次级时序复验，不称为严格首次接触前预警。

上一阶段 BCE 的边界 FAR 未通过不能通过换一个名称抹去；本轮将在独立开发/校准数据上选择更保守工作点，再用新测试验收。BCE 作为常见事件概率参考并不意味着预设它必胜。

严重度 Replay 首轮仍给网络单阈值标签，额外幅值只控制记忆保留。因此它与二值平衡的差别能够归因到记忆；若同时换 CDF 头，就无法隔离这个因素。CDF 的表示×记忆交互安排在主比较之后。

## 4. 场景序列：先隔离几何变化

| 域 | 地形 | 作用 |
|---|---|---|
| A | 平地 + 粗糙地，粗糙幅度 1–4 cm | 初始已知分布 |
| B | 上/下坡，坡度参数 0.05–0.25 | 第一阶段新几何 |
| C | 上/下阶梯，高度 2–10 cm | 第二阶段新几何 |
| U | 新实例随机块，高度 2–10 cm | 始终未进入训练的静态分布外探针 |

主序列 **A→B→C**；A→C→B 检查顺序敏感性，列为次级，不与主序列混算 seed 数。无变化控制 **A→A→A** 重采样同一 A 训练池，用于检测继续优化本身的漂移；它不是新数据流匹配对照，须保留这一限制。

每个阶段结束都评价 A/B/C/U 的固定集合，但只把已学过的域称为“旧域”。例如 C 尚未训练时的低 AP 属于未适应，不能计作遗忘。U 永远不进入模型/超参数/校准选择；其结果是跨场景泛化，不是旧能力保持。

阶段末只“返回评价 A”不等于再次训练 A。若后续做 A→B→C→A 的重新学习，应另采新 A 训练 episode，另外比较恢复速度，不复用旧训练帧冒充新观测。

## 5. 数据、开发与最终测试隔离

**pilot 与确认性阶段分别重新采集 compact 数据。** 原阶段二进制数据已按用户要求清理，权重/报告可指导研究设计，但不再依赖旧 cache 运行。pilot 使用 seeds 901/902/903，分别采 train 2500、monitor/calibration 各 600 步，仍为 4096 env、400 Hz；一个独立 pilot 重复只用于工程与选型，不充作正式五组证据。原阶段测试已被查看，不能继续用于选择内存比例、严重度阈值或新网络后，仍当作未知测试。

正式候选为五组独立采集：train seeds 1501–1505，monitor 2501–2505，calibration 3501–3505，test 4501–4505。每次 4096 env；每组 train 2500 步，其他角色各 600 步。不同角色使用不同地形生成 seed，机器人共享地形块的相关性继续按地形层级处理。

- train：只有当前已到达块的标签可用于梯度；以前块只能通过受限 buffer 访问。
- monitor：固定旧/新域曲线，用于观察能力漂移；正式阶段按固定计划更新，不用它为某个方法单独调参或决定停止。
- calibration：按地形块而非相邻帧，进一步拆为概率拟合、阈值选择、独立阈值验证；各方法访问完全相同的角色。
- test：全部方法及 checkpoint 序列锁定之后，统一评价；测试分数不参与回传、阈值选择或版本内重训练。

所有 split 保留完整 episode、终止前区间及固定 500 ms 起始排除规则。报告失败率和有效暴露，不只评价幸存轨迹。不能随机拆相邻帧或跨 episode 拼六帧历史。

上一阶段“多类地形训练好的模型”不能当 A-only 初始化，B/C 信息会提前泄漏。每个数据 seed / 初始化重新只用 A 训练 Stage-0，并保留匹配的 optimizer 状态。之后所有方法从同一个 Stage-0 状态克隆。

## 6. 流程和计算预算

候选 Stage-0 为 60,000 次 Adam 更新；B、C 各 20,000 次。每个新域按采集时间切成五个 500 策略步的到达块，每块 4,000 次更新。标签一旦在当前块提供，可以在该块预算内重复训练；这叫**分块持续监督学习**，不是严格每条样本只更新一次的 online-learning 协议。

每块顺序固定为：

1. 当前模型先预测完整到达块，记录学前/prequential 指标，再开放这些标签给优化器。
2. 用当前块与之前的 buffer 训练；总 batch 始终 2048，Replay 比例 ρ=0.5，即 1024 当前 + 1024 旧记忆。
3. 训练完成后，按原时间顺序将该块每条唯一记录插入一次 buffer。不能每次重复抽到就重复入库；后续回放也不能增加入库计数。
4. 当前块在退出后从优化器的数据权限中移除；旧数据只有 buffer 内的完整载荷可读。

finetune 用 2048 当前样本，Replay 方法用相同总数的混合样本。两者总计算相同，但新样本曝光次数不同，这个代价必须报告；不宣称同时匹配了新样本曝光。finetune 已覆盖“把同样计算全用于当前块”的对照。

候选适应学习率 1e-4，Stage-0 候选 1e-3；不在任务边界清空 Adam 状态，所有方法相同。每 1000 更新记录 monitor 指标；固定最后一个 checkpoint 为阶段结果，不事后挑最优点。Stage-0 的容量/更新充分性及学习率在独立 compact pilot 上核对后，写入新 lock 文件，正式实验中不随测试更改。

A→A→A 控制使用相同更新计划。需要保存 RNG、块游标、optimizer、buffer、归一化、标签版本，才能断点后继续同一条实验流。

## 7. 最小方法矩阵

| 方法 | 用途 |
|---|---|
| Freeze | 测更新前跨域缺口；对照固定模型的旧域稳定性，零适应更新 |
| Finetune | 只学当前块，确认遗忘及新域可塑性 |
| FIFO | 同预算只保留最近历史，检验是否只是短时上下文有帮助 |
| Uniform reservoir | 从全部过去训练记录做随机 reservoir；核心强基线 |
| Binary-stratified reservoir | 按有/无 >2000 N/s 事件分层，控制普通类别平衡作用 |
| Severity-stratified reservoir，带采样校正 | 候选小模块：保留非事件、中等及更强冲击覆盖 |
| All-past reference | 能访问所有已到达训练数据、batch/更新相同；不受内存预算约束的参照，不保证是真正性能上界 |

首轮核心固定 **8 MiB 记忆**。1/32 MiB 与 ρ=0.2 为次级敏感性，避免先跑大量组合后挑最有利设置。所有方法都存机器人区间和四足标签，不将四足拆成独立数据来源。

内存预算包含展开的本体历史、标签、动作、来源和时间元数据、已存预测、reservoir 计数器/RNG、索引/去重表与待完成片段。不得只存一个行号，却让优化器无限回读磁盘上的旧轨迹。数据 payload、可序列化总量与实际分配存储分别报告；训练 optimizer/GPU 工作区另列为计算资源，不混作 Replay 存储。

## 8. 候选记忆机制与必要消融

记忆单元先采用**一条具有完整因果历史的机器人策略区间**。令 `s=max_foot S20`：普通二值参考按 `s≤2000` / `s>2000` 分层，容量配额 1/2、1/2；严重度候选按 `s≤2000`、`2000<s≤4000`、`s>4000` 分层，配额 1/2、1/4、1/4。4000 是待 pilot 锁定的幅值阈值，不从最终测试分位数计算。

每层内部做真正的 uniform reservoir，同时累计过去唯一记录的层计数 N_s。主方法校正回放层的采样先验：若该次旧样本抽取层概率为 q_s，回放损失乘 `(N_s/N)/q_s`。层样本不足时须记录实际 q_s，空层不给零概率却有正目标质量的虚假校正；主方法不额外裁剪权重。这个校正对应过去已到达训练流的区间分布，不保证未来新场景概率正确。

该机制只改变记忆覆盖与抽样，事件 BCE 目标和网络不变。每层 reservoir 只有有限样本，校正也不能恢复已经丢失的所有状态；可能收益是以固定字节覆盖稀有严重度，可能代价是有效样本减少或梯度方差增加，两者都应实测。

必须增加 **相同记忆、不加权训练** 消融。如果收益仅存在于不加权版本且自然分布 Brier/FAR 恶化，就应解释成代价敏感训练或事件先验改变，而不是无代价改善了记忆。

首轮不把高损失优先回放叠进来，以免模型自身错误反复强化。之后如研究困难负例，应保持同样的采样校正、字节预算和普通 class-balance 对照。

“事件片段”属于第二层消融：只有区间级比较有实质问题时才做。事件附近片段必须与相同长度的随机片段比较；同时控制每次更新的有效损失区间数、重叠样本和完整历史开销。必须等片段所需后续数据真正到达后才能入库，不能用未来 force 提前触发当下预测。不能仅因存了更多历史或正类样本就声称时间结构创新。

## 9. 能力漂移与阈值漂移分别评价

每个学习节点产生一张“训练到当前阶段 × 固定评价域”的矩阵，记录 AP、自然频率 Brier/log loss、分载荷数值误差、事件召回和实际 FAR。对同一个旧域的学习后成绩与后续成绩做差；不比较不同阳性率地形的 AP 绝对高低来判断遗忘。

主遗忘量为 A、B 各自在第一次学完后的 AP 减去学完 C 后的 AP，再平均。正值表示退化，也允许负值表示后向迁移。另报最差退化和按固定时间表的学习曲线面积，不只汇报最后一张图。

风险工作点分开：

1. **固定初始 A 校准器和阈值**：检查旧 A 决策能否保持；原阈值在新 B/C 的表现也记录，但失败不能自动判作遗忘。
2. **显式拥有校准标签的诊断**：相同校准访问权限下，分开重拟合单调概率映射、重选报警阈值，检查失效能否被修复。这属于有验证数据的 oracle，不是无监督部署能力，也不能用于优化模型权重。

单调校准不提升 raw AP；AP 未变而固定 FAR 失控与 AP 明显下降是不同现象。报警规则沿用同足事件分组、两步合并、100 ms 越阈抑制及一对一匹配。固定阈值/重校准阈值都分别报告，不把二者混成一个最优成绩。

为避免上一阶段贴边误报，候选在阈值选择集合以经验 FAR≤0.5 选择最高召回点，然后在地形块独立的验证集合检查区间上限≤1。验证失败保留失败，不继续用该验证集合反复收紧阈值。最终工作点仍在新 test 验收；没有非平稳分布下的自动保证。零误报时退化成全零的 bootstrap 也不能当作 FAR 已知为零。

第一轮固定监测集合主要提供**可审计的漂移曲线**，不根据监测报警控制训练。若以后声称自动发现漂移，需要额外评价检测延迟、整段无变化流误报概率和多次查看的影响；不能将固定监测本身包装成已验证的漂移检测算法。

## 10. 成功标准与统计

五组独立采集、每组两次初始化；先平均初始化，再做数据 seed 配对比较。地形块在同类别内重采样，四足和连续帧都不当成独立重复。

1. **先证遗忘**：finetune 的旧域退化相对 A→A→A 和 Freeze 有一致差异；同时确认新域确实学好了。若没有明显退化，就报告本设置下 Replay 非必要，不能通过欠训练 Stage-0 或事后扩大 shift 制造成功。
2. **证明 Replay 有作用**：随机记忆相对 finetune 改善旧域保留，同时报告新域代价。
3. **验证候选增量**：严重度加权记忆相对 Uniform 和 Binary 两个参考，最终旧域 macro AP 配对改善须超过 0.01；两个方向性优效比较对 +0.01 边界作 Holm 校正。报告逐 seed 效应与逐项 95% CI，不能只给 p 值。
4. **新域非劣**：候选对每个上述参考的新 C AP 差值 95% CI 下界须 >−0.01；若不满足，报告稳定性—可塑性权衡。
5. **报警用途的额外门槛**：只有固定工作点上双方的实际 FAR 区间上限都≤1，且配对召回增益区间下界>0.03，才称报警效用改善。只提高 AP 只能称排序/保留改善。

前两项的实际波动和统计裕量先由独立 compact pilot 检查，正式确认前固定最小效果与分析脚本。上述候选判据不能在看新 test 后放宽。若未达到，结论是无明确收益或不确定，不以单个 seed/内存容量中的最好结果替代。

## 11. 资源与实施顺序

上一阶段已按用户要求释放约 220 GiB，仅保留代码、有效权重、报告及关键元信息。新阶段主任务不再保存所有高频 I2 特征或重复展开每条 270D 历史，也不同时累计完整 raw 与重复 cache。

新采集器应流式生成与 v1 精确同定义的标签，保存 compact pre/post 45D、动作、F20/L20/S20、终止/episode/地形元数据；预先固定 0.5% 原生接触轨迹审计样本，核对标签和 reset 时序。新 compact collector 必须先做开关不干扰对照和 4096 env 短测，不以新格式未经验证就开始全量。

正式候选共 88,064,000 个机器人区间。按每区间上限估计 480 B，核心 compact 数据约 39.4 GiB；pilot 约 6.8 GiB，另计审计轨迹、模型、图和临时文件；历史快照约 180 MiB。开始新全量采集前必须测实际字节率与临时峰值，预计结束后至少留 15 GiB。数据保留周期和完成后压缩/清理范围预先记录，不再默认长期保存全部原始轨迹。

执行顺序为：

1. 本轮：保存 v1、写本方案；不启动新训练。
2. Pilot：新 compact pilot 上重建 A-only Stage-0，做 Freeze/Finetune/Uniform 与 A→A→A，核对是否存在实质问题，检查学习预算。
3. 实现内存权限、字节核算、唯一插入、采样校正、checkpoint 恢复及 compact collector 的契约验证；锁定方案版本和所有比较。
4. 新 4096 env 数据，正式五组配对复验；先完成全部模型/节点锁定，再统一最终测试。
5. 主结论明确后，再决定是否值得做片段记忆、CDF×记忆、A→C→B 和存储敏感性；它们需要另列次级假设，不能替代主实验失败结果。

## 12. 可以讲的研究故事与创新边界

如果结果支持，故事是：**本体感觉可以学习有限时间尺度的载荷与冲击风险；新场景监督更新可能损害已有能力；在固定内存与算力下，利用物理严重度覆盖并控制采样先验，可以改善风险模块的保留与适应权衡。** 它是独立估计/监测模块，不依附旧 learned admittance。

Replay、reservoir 和类别平衡已有充分先例，不能把它们本身当成创新。小记忆混合训练的强基线见 [Chaudhry et al.](https://arxiv.org/abs/1902.10486)；不平衡流的 class-balancing reservoir 见 [Chrysakis & Moens, ICML 2020](https://proceedings.mlr.press/v119/chrysakis20a.html)；多标签分区 reservoir 还有 [PRS 作者代码](https://github.com/cdjkim/PRS)。Go1 的四足关联与严重度分层也不自动产生方法新颖性。

真正需要检验的增量是：**相同二值预测头、相同预算下，连续物理严重度覆盖比普通二值平衡记忆多保留了什么，是否还能维持自然分布风险质量和新域学习。** 若只胜随机而不胜普通二值平衡，结论应为已知平衡机制在该问题上有效，候选创新不足。

若最后仅发现阈值漂移，研究重点应转向校准与可靠工作点；若无明显遗忘，保留冻结估计器可能已足够；若出现无法兼顾的新旧冲突，再检查隐变量、域条件化和输入信息。任何一条都比预先承诺 Replay 必须有效更有价值。

本阶段最多验证仿真中有 privileged contact 标签的顺序适应。真机没有同等接触监督时，不能直接声称能够在线监督更新；PPO 策略变化、动作条件化、真实传感时延以及闭环安全收益需独立阶段验证。
