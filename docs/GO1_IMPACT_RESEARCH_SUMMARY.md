# Impact研究总复盘与下一阶段实验

日期：2026-11-08。覆盖原MC/Go2W记录、Go1/Isaac Lab已完成实验及下一阶段设计。数值引用既有报告，不重新选择历史测试工作点，不覆盖原结论。下一阶段尚未执行。

## 当前研究定位

已经证实：固定Go1策略下，本体历史包含接触加载信息；连续回归可以学习有限时间尺度的力与loading-rate；直接事件监督在部分风险决策任务中更合适；顺序更新会损害旧分布能力。

尚未证实：一个能在下一次强冲击前留下足够动作时间、低误动作、跨场景稳定，并通过Replay持续保留能力的本体模块。额外门控、有序严重度和事件Replay均未取得可概括为算法创新的稳定优势。原MC控制失败也不能归为分类器或Replay的单独失败。

下一步研究**下一次落足的强冲击风险及有效提前量**；接触后识别保留为诊断，动作收益单独验收。

随后补充的共享trunk差异见[机制对照计划](GO1_IMPACT_SHARED_REPRESENTATION_PLAN.md)：既有Go1独立网络结果不直接回答原Estimator多任务head的表现。下一轮需在同一冻结行为轨迹上区分表征、联合梯度与特征持续变化，不先认定共享一定有害。

## 实验基座

Go1基线为`Unitree-Go1-Velocity-PD`，Kp40、Kd1、action scale0.25。原baseline物理200Hz、策略50Hz；Actor使用当前45D及HIMEstimator从270D历史估计的3D速度和16D latent，Critic训练时使用238D privileged observation。HIM-PPO、独立Estimator、prototype/Sinkhorn/swap loss未因impact研究修改。

Impact模块独立监督，主要输入45D×6=270D；Go1各轮冻结Actor和原HIMEstimator，contact只用于训练标签、审计与评价。没有Go1的PPO重训、导纳/quiet奖励或新增真机实验。第一步物理200Hz，后续正式研究400Hz，策略与主要本体输入仍50Hz。

每次4096总环境共享84块12m×12m地形：平地、1–4cm粗糙面、上下坡、2–10cm上下台阶、2–10cm随机箱块；箱块整类不参与估计器训练/选点。4096不等于独立地形数量。早期固定0.7m/s、6秒episode；后两阶段为0.4–0.9m/s、4秒episode，并留出1.0–1.1m/s。起始平台包含于数据，不能把地形类别结果解释为全部是障碍接触。

## 已有证据应如何解释

**MSE能学，但精度要有时间尺度、单位与分布。** 后续F20是20ms均值力，L20是其20ms滞后正差分；传感量为法向合力向量模长，不是含摩擦三维外力，更不是硬件真值。400→800Hz时，原生力峰/单步正差分峰的配对差异中位数约67.36%/121.42%，F20/L20约1.97%/4.51%，支持有限物理时间窗目标。P20 held-out高loading子集的L20 MAE约1172.51N/s、p95约3370.55N/s；整体误差低不保证尾部或控制容差。不能直接外推到UniFP机械臂的有符号力方向误差。

**事件监督的优势不等于BCE的普遍优势。** 同二值目标的概率MSE/Brier已在力/loading-rate阶段实现，说明改变目标也能改善报警。可观测性阶段BCE/MSE排序接近，连续流任务又不同；任务、背景、时间与报警规则必须一起说明。有序约束、分布回归也没有被证明普遍失败或普遍优胜。

**Replay有条件效用，当前没有可概括的正/负总判决。** 原MC旧样本是追加到online batch，小比例0.25对应混合后20%；Go1主实验固定总batch，一半旧样本替换新样本，当前样本曝光减少。数据、动作、监督、目标和预算都不同，不能简单归因于reward。估计器由监督损失更新，reward通过控制行为/接触轨迹间接影响分布。Go1全历史参照旧域AP0.9670高于微调0.9420，说明覆盖值得研究，但不足以锁定容量为唯一原因。

静态冻结模型在未知箱块上变差是泛化问题；同一旧测试集随更新退化是保留问题。无需先解决全部未知域泛化才比较Replay，但必须有相同未来目标、新域监督与独立旧/新固定集。

**后续指标下降不等于同一能力突然退化。** 事件对齐AUC约0.97是在已知何时落地时区分强弱；连续流召回43%还要求找时刻、排除背景、去重、低FAR、40ms截止。相同冻结头配因果真值触发有65.86%检出，学习触发降到3.30%，适配后回到44.67%；这支持使用分布不一致重要，但背景、时刻偏差与额外更新尚未单独归因。

直接连续BCE在普通/提速箱块的FAR达7.577/17.069次/机器人分钟；上一阶段弱落地FPR已从正常2.52%升至普通箱块6.33%、提速箱块23.34%。阈值迁移困难早已出现，高AP不能替代可靠工作点。

**目前仍没有可用提前预测与动作收益的证据。** P20包含已接触后的继续加载，预测区间长度不是保证提前量；pre-last依赖真值选样。连续BCE命中报警仅约45.88%早于所分析40ms窗内原生力最大值，且没计入执行响应。额外20ms延迟、沿用原阈值时正常召回仍35.20%，但无效报警17.966/min，其中98.50%是40–80ms的超时强事件；不能说信息完全消失。隐藏地形分支的特定噪声/先验下界也不能套用到所有自然步态，概率预测未来不违反因果律。

## 下一阶段核心问题

**在完整连续行走中，本体感觉能否在下一次强落足之前提供超过相位规律的信息，并留下足够动作时间？** 对照与主判据见[详细计划](GO1_IMPACT_ANTICIPATION_PLAN.md)。先定位为可证伪的未来风险模块，不将旧learned admittance、quiet gait或控制网络结构带回主任务。

### N0：时间/动作响应开发检查

在独立开发地形上记录观测截止、几何接触/5N起点、原生力峰和滤波率峰，分别标明普通落足、短重接触、支撑再加载和立面碰撞。若缺可靠几何接触审计，只能说力阈值前，不能声称严格无接触预警。

先用一种幅度受限的短时预备动作做20/40/60ms提前分支，检查动作在何时实际生效。候选可为依据部署关节运动学调整摆动末端下摆速度，不默认admittance或改PD必然有效。先做无干预A/A，确认完整状态恢复或共同前缀重演误差远小于干预效应；复制root/joint状态不等于复制全部PhysX接触求解历史。

20ms为首个报告档位，并非已验证的执行器响应时间。若动作需要更久，在正式预测训练/测试前锁定更长最低提前量，20/40ms结果仍保留。80ms预测窗也需在开发阶段确认足够，不能看测试后临时延长。若动作无效，保留风险预测实验，但不给出减冲击收益主张。

### N1：下一轮正式主实验——未来强落足风险

每足输出未来80ms内**下一次落足为强冲击**的概率。下一次若为普通落足，不能跳过它匹配更后面的强事件。首版沿用已审计的40ms低力、两个>5N样本、2000N/s平滑率阈值，阈值不是损伤界限且不覆盖所有冲击。落足后40ms的严重度只在未来成熟后作监督，绝不作为当前输入。尾部需覆盖80+40ms，跨episode或未来不完整时删失，不补零负例。

| 模型/参考 | 目标 |
|---|---|
| 常数风险、相位/落足时序BCE | 排除正例比例和周期落足规律 |
| 完整270D历史、未来事件BCE | 最简单未来风险基线与预设主模型 |
| 同输入同二值目标概率MSE/Brier | 新未来目标下保留损失对照，不重复宣称首次发现 |
| 同输入、未来连续严重度MSE | 数值/尾部精度与风险参考 |
| 时间×强弱联合概率输出 | 候选模块，区分何时落足与是否强冲击，不硬触发冻结头 |

联合头每足分(0,20]、(20,40]、(40,80]ms三时间档，每档普通/强，再加80ms内无落足，共7类。与简单BCE比较时使用同一未来强事件概率和报警规则；若利用时间档过滤过近事件，需增加同一“可动作窗口”二值标签参考，分离决策规则与结构。更多监督与参数不是免费优势。

共同条件：4096总环境，5独立数据×2初始化，400Hz物理、50Hz策略/主要输入，0.4–0.9m/s、4秒episode；六家族训练、箱块留出，另测1.0–1.1m/s。每组拟train2500、validation/test/high_speed各600步，共88,064,000个机器人区间，平台/障碍区分报告。新的seed和采集细节见计划。初始预算60000更新、batch2048，独立开发集检查收敛后正式锁定；同输入模型配对从头初始化，不用不同旧头混淆损失对照，不按最终测试为个别模型延长训练。当前已生成动作可作单列输入消融，不读取未来实际动作序列。

主指标：满足最低有效提前量的强事件检出率，配以验证锁定工作点的无效动作率。有效提前量=接触起点−动作最早可生效时刻，传感、推理、通信和执行死区各计一次；最低提前量是响应开始后所需的剩余动作时间，不再次扣除执行死区。50Hz不意味着固定20ms链路延迟。另报额外10/20ms链路时延，不制造中间传感帧。

验证选点上界<=0.5次/机器人分钟，主测试要求上界<=1/min，四足合计；另报0.5/1/5预算曲线用于动作代价分析，不替换主判据。全部模型/阈值先锁，再开测试。普通、纯背景、过晚强事件及重复动作分别计数，保守主预算将未及时命中的预备动作均视为无效动作。

主科学判据：普通速度训练家族的新轨迹上，完整BCE相对相位BCE的有效提前检出率配对95%CI下界>3个百分点，双方工作点达标；平均两初始化后按5数据组推断，另有tile聚类统计。箱块与提速检验迁移；达不到相应域预算，不声称该域可用。条件于未来确有落足、相近相位/指令/足/地形的强弱区分仅作离线诊断，不代替全流主指标。3个百分点是科学推进门槛，不是通用实际收益标准。

### N2：同一未来任务下的适配与Replay

N1显示可用提前信息后即可引入新分布，不要求先解决全部未知域。固定行为策略，A→B→C→A；比较freeze、finetune、Stage-0 anchor、同字节随机Replay与同计算近期样本重训，全历史作资源参照。先不把未获支持的严重度分层作为主创新。

开发对照为8MiB、混合后20%/50%旧样本；正式比例与模型数在开发阶段锁定。披露固定总batch替换新样本的代价，必要时补等新样本曝光/等计算参考。保留旧/新固定集，分别记录提前检出率、无效动作、AP/Brier、提前量与排序/阈值漂移。

先预测再更新，未来标签成熟后入库；保存的是预测时刻因果历史及未来标签，不能混入旧任务已发生标签。策略/预备动作若改变，保存已知动作或计划条件、策略版本与时尺度，不能将动作导致的目标变化误称遗忘。仿真成熟标签不等于硬件无标签在线适应。

### N3：物理收益验收

固定预测器及同一预备动作后，对比无预备、相位触发、风险触发、次数/提前时刻/幅度配平的随机参考，以及用无干预未来标签安排的非部署诊断参照。分支共同前缀需可复现，诊断参照不是可部署或真正性能上界。

按固定无干预风险事件集合评价，干预降低冲击或延迟落足后也不删分母。记录有限窗加载、loading-rate、冲量、跟踪、姿态、跌倒和动作成本，避免单步峰值随物理dt变动制造收益。参照也无收益时先检查动作/时间；参照有效而风险触发无效时检查预测/门限。

风险触发在配平资源后优于相位触发、并产生可复验物理收益，才支持小模块创新。候选故事是：**有时间语义的未来强落足概率，为有限提前量动作决策提供有效信息，并在持续适配中保留它。** 这是一组待检验主张，不是目前已完成的成果。
